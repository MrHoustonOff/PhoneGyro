# PhoneGyro: лендинг

Статический сайт без сборки и зависимостей. Выложите содержимое папки на хостинг или откройте локально через любой веб-сервер (`python -m http.server`).

## Структура

- `/index.html` — русская версия, `/en/index.html` — английская. Это отдельные страницы со своими заголовками, описаниями и разметкой; между ними связаны `hreflang`, переключатель RU/EN — обычные ссылки.
- `brand.css` — фирменный цветной слой (плитки, мозаика с кольцами, выделения в заголовках), `landing.css` — базовая раскладка.
- `site.js`, `scene.js` — тема, 3D-сцены, анимации прокрутки и эффекты. Анимации включаются только на компьютере с мышью и выключаются при «уменьшить движение».
- `three.min.js`, `gamepad-data.js` (встроенная 3D-модель), `ds/phonegyro/` — дизайн-система и шрифты.
- `404.html` — страница «не найдено» в фирменном стиле. Все пути в ней абсолютные, потому что она открывается по любому адресу.

## SEO и нейросети

- Заголовки, описания, canonical, hreflang, Open Graph и Twitter-карточки (`og-image.png`, `og-image-en.png`).
- JSON-LD на каждой странице на своём языке: SoftwareApplication (с возможностями), HowTo (4 шага), FAQPage (7 вопросов), WebSite.
- Блок «Коротко» — факты о программе списком определений, их легко цитировать людям и ИИ-ассистентам.
- `llms.txt` (сводка) и `llms-full.txt` (полный текст обеих версий) в корне — для ChatGPT, Claude, Perplexity и других.
- `robots.txt` открыт для поисковиков и ИИ-краулеров, `sitemap.xml` с обеими версиями.

## Перед публикацией

1. **Адрес сайта.** Везде стоит `https://mrhoustonoff.github.io/PhoneGyro/`. Если адрес другой, замените одной командой:

   ```
   grep -rl "mrhoustonoff.github.io/PhoneGyro/" . | xargs sed -i 's#https://mrhoustonoff.github.io/PhoneGyro/#https://ВАШ-АДРЕС/#g'
   ```

2. **«Скачать для Windows»** открывает `releases/latest`. Для скачивания в один клик подставьте прямую ссылку на файл релиза.
3. Если документация (VitePress) будет на том же домене, положите её в подпапку `guide/`, лендинг оставьте в корне.

## Хостинг

- **GitHub Pages:** содержимое папки — в ветку `gh-pages` или в папку `/docs`, затем включите Pages в настройках репозитория (`.nojekyll` уже есть, `404.html` подхватится сам).
- **Cloudflare Pages или Netlify:** укажите папку как есть, команду сборки оставьте пустой (`_headers` настроит кэш).

## Продвижение

1. Добавьте сайт в [Google Search Console](https://search.google.com/search-console) и [Яндекс Вебмастер](https://webmaster.yandex.ru), отправьте `sitemap.xml`.
2. В репозитории заполните About: ссылка на сайт, описание, темы (`gyroscope`, `dsu`, `cemuhook`, `motion-controls`, `emulator`), ссылка на сайт в начале README.
3. Ссылки извне: списки DSU-источников, профильные форумы и сообщества эмуляторов, видеообзор.
4. Проверка: [Rich Results Test](https://search.google.com/test/rich-results), [opengraph.dev](https://opengraph.dev).
