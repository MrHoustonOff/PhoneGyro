# Обновления

PhoneGyro ***не обновляется сам***. Он умеет только сообщить, что вышла новая версия, а скачать и заменить файл вы можете сами.

## Проверка обновлений

Проверка ***по умолчанию выключена***. Включается в [Настройках](settings.ru.md): **«Проверять обновления при запуске»**.

> [!NOTE]
> Это ***единственное обращение PhoneGyro в интернет***. Пока пункт выключен, программа полностью офлайн. О вас ничего не отправляется: приложение только спрашивает у GitHub номер последней версии.

Когда проверка включена, PhoneGyro спрашивает GitHub вскоре после запуска и затем раз в несколько часов. Если проверка не удалась, она повторяется с растущей задержкой.

## Статус в подвале

Справа внизу окна показан статус проверки, версия и канал сборки.

![Подвал окна](imgs/footer.webp)

| Статус | Что значит |
|---|---|
| отключено | Проверка выключена. Нажатие открывает настройки. |
| проверка… | Идёт запрос к GitHub. |
| актуально | Установлена последняя версия. Нажатие запускает повторную проверку. |
| доступна 2.x.x | Вышла новая версия. Нажатие открывает страницу релиза. |
| ошибка | Проверить не удалось. Нажатие повторяет попытку. |

## Когда вышла новая версия

Появится окно с номерами версий и ссылкой на страницу релиза с описанием изменений. Его кнопки: **Скачать**, **Позже** и флажок **«Не напоминать об этой версии»**. Более новая версия снова покажет окно.

## Как обновиться

1. Скачайте новый `PhoneGyro.exe`.
2. Запускайте теперь только его. Старый файл можно удалить.

***Настройки и профили сохраняются***: они лежат в [папке данных](data.ru.md), а не рядом с exe. Сертификат для iPhone тоже сохраняется, переустанавливать его не нужно, кроме случаев из [Сертификатов и TLS](tls.ru.md).

## Каналы сборок

Номер сборки имеет вид `2.0.2.017-dev`: версия релиза, число коммитов сверху и канал. В подвале рядом с версией стоит бейдж канала:

* ***release*** — сборка точного релизного тега, то, что вы скачиваете со страницы релизов;
* ***dev*** — сборка из ветки разработки между релизами, возможны нестабильные места.

Проверка обновлений сравнивает вашу версию с ***последним опубликованным релизом*** на GitHub, а не с dev-сборками.
