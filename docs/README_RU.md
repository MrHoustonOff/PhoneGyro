# PhoneGyro

> [!IMPORTANT]
> **Раньше назывался GyroBridge.** С версии v2.0.0 проект называется PhoneGyro. Все релизы GyroBridge v1.x устарели и считаются крайне нестабильными — используйте v2.0.0 или новее. Переноса данных с v1.x нет: заново установите сертификат на iPhone/iPad и откалибруйте устройство. Подробности — в [заметках к релизу v2.0.0](RELEASE_NOTES.md).

> 📖 **Подробное руководство пользователя**: [Русскоязычное руководство](guide.ru.md) | [English User Guide](guide.en.md)

PhoneGyro превращает ваш смартфон (iOS или Android) или USB-контроллер (Arduino Nano + MPU-6050) в контроллер движения для ПК-игр и эмуляторов по протоколу Cemuhook DSU.

## Быстрый старт

### 1. Скачивание
Скачайте `PhoneGyro.exe` (или `PhoneGyro-windows-arm64.exe` для Windows-устройств на процессорах ARM) со страницы [GitHub Releases](https://github.com/MrHoustonOff/PhoneGyro/releases).

### 2. Запуск
Убедитесь, что ваш ПК и смартфон подключены к **одной локальной сети Wi-Fi**. Запустите `PhoneGyro.exe`.

### 3. Подключение устройства
Выберите источник вверху окна: **Смартфон** или **USB-контроллер**.
- **iOS (iPhone / iPad)**: Нажмите **Начальная настройка** в приложении и выполните пошаговую установку локального профиля сертификата, необходимого Safari для доступа к гироскопу через HTTPS.
- **Android**: Отсканируйте QR-код на главном экране камерой и откройте страницу контроллера в Google Chrome.
- **USB-контроллер** (Arduino Nano + MPU-6050): прошейте [референсную прошивку](https://github.com/MrHoustonOff/PhoneGyro_hardware_protocol) (протокол 1.1+) и воткните кабель — PhoneGyro сам найдёт его на любом COM-порту.

### 4. Калибровка — обязательный шаг
Нажмите **Калибровать** и пройдите мастер (покой, кивок, крен, совмещение осей — около минуты). Именно калибровка сообщает PhoneGyro, где для вашего хвата «вперёд» и «вправо»; **без неё прицел двигается не по той оси или в обратную сторону.** Достаточно одного раза на устройство и хват; профили телефона и USB раздельные.

### 4½. Выбор профиля и центрирование
При первом подключении PhoneGyro откроет окно центрирования: держите устройство так, как будете держать его в игре, выберите в нём профиль калибровки и нажмите **Центрировать**.

### 5. Настройка эмулятора
В настройках управления вашего эмулятора укажите параметры сервера движения:
- **IP сервера**: `127.0.0.1`
- **Порт сервера**: `26760`
- **Протокол**: Cemuhook DSU

> Прицел мелко дрожит, когда вы замерли? Поднимите **порог дрожи** в настройках (отдельно для телефона и USB). Подробнее — в [руководстве](guide.ru.md).

## Расширенные настройки и персонализация

Нажмите кнопку **Настройки** в верхней панели для доступа к параметрам:
- **Интерактивный тестовый стенд**: Осциллограф в реальном времени, 3D-видоискатель прицеливания и стенд наклона платформы для проверки отклика и фильтров перед игрой.
- **Пользовательские порты**: Настройка портов Cemuhook DSU (`26760`), HTTP сопряжения (`8080`) и HTTPS контроллера (`8443`) с валидацией и защитой от конфликтов.
- **Порог шума (Deadband) и чувствительность**: Подавление микро-дрожания сенсора в покое мягким порогом и масштаб отклика гироскопа. Само движение передаётся без сглаживания и с коррекцией дрейфа (см. [Пайплайн движения](motion-pipeline.md)).
- **Глобальный масштаб интерфейса**: Настройка масштаба шрифта и элементов (`0.80x` - `1.40x`) с поддержкой горячих клавиш (`Ctrl +`, `Ctrl -`, `Ctrl 0`).
- **Звуковые сигналы**: Выбор между синтезированной мелодией, системными звуками Windows и тихим режимом.
- **Оформление**: Переключение между темной и светлой темами интерфейса в стиле Apple.

## Безопасность, антивирусы и открытость

PhoneGyro — это полностью бесплатный проект с открытым исходным кодом под лицензией MIT. В приложении нет телеметрии, сбора данных, рекламы и внешних сетевых подключений к интернету — весь обмен данными происходит исключительно внутри вашей домашней локальной сети Wi-Fi между ПК и телефоном.

### О ложных срабатываниях антивирусов (False Positives)
Для независимых разработчиков открытого ПО приобретение корпоративных цифровых сертификатов подписи кода (EV Code Signing) стоит неоправданно дорого (сотни долларов ежегодно). Из-за отсутствия коммерческой подписи эвристические алгоритмы машинного обучения некоторых антивирусов (например, эвристические метки `!ml` у Microsoft Defender) могут ошибочно помечать свежескомпилированные бинарные файлы как подозрительные.

Мы непрерывно проверяем релизы на VirusTotal (69+ систем признают файл абсолютно чистым). Если у вас есть какие-либо сомнения:
- **Проверьте исходный код**: Вы можете лично изучить каждую строчку кода в этом репозитории или загрузить код в любой ИИ-ассистент (ChatGPT, Claude, Gemini и др.) для независимого аудита безопасности.
- **Соберите самостоятельно**: Скомпилируйте бинарный файл из исходников на своем компьютере с помощью Go и Wails за 2 минуты (инструкция ниже).

## Сборка из исходников

Требования:
- [Go](https://go.dev/) 1.21+
- [Node.js](https://nodejs.org/) 18+
- [Wails CLI v2](https://wails.io) (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`)

```bash
# Клонирование репозитория
git clone https://github.com/MrHoustonOff/PhoneGyro.git
cd PhoneGyro/gui

# Сборка под Windows x86_64
wails build -tags native_webview2loader -o PhoneGyro.exe

# Сборка под Windows ARM64
wails build -tags native_webview2loader -platform windows/arm64 -o PhoneGyro-arm64.exe
```

Скомпилированные файлы появятся в директории `gui/build/bin/`.
