Changelog:

- Settings show whether Windows Firewall lets the phone connect, with an "Allow" button (asks for administrator rights). In phone mode the app reminds you at every start while it is blocked, for example after the Windows prompt was dismissed
- Optional update check at startup (Settings, off by default): if a newer release is out, a window links to the download and the release page. This is the only internet request PhoneGyro makes
- Settings show the data folder with a button to open it; the guide explains where data is stored and how to remove PhoneGyro completely
- Profiles show when they were calibrated (in the profile menu and under the active profile; the full date and the app version are in the tooltip). Profiles saved before this version show no date
- Profiles are marked outdated only when a new version really needs data they lack, not on every update: the app keeps a range of supported calibration versions
