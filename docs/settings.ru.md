# Настройки

Все настройки применяются сразу, кнопки «Сохранить» нет.

У каждого пункта есть значок ⓘ: наведите на него курсор, чтобы прочитать, что делает пункт и какое значение выбрать.

В разделе настроек также есть мини-игра: в ней удобно проверить, как ощущается управление с текущими параметрами.
