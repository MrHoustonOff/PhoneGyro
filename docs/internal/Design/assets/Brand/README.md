The brand files: the cleaned supplied logo, three app-icon sketches, the UI glyph and the tray icons.

- `logo-mark.png`: the supplied full-colour logo with stray specks removed, transparent, 512px. Not themeable; use for splash, installer and docs headers until it exists as SVG.
- `icon-slate`, `icon-paper`, `icon-orb`: app icon sketches (SVG and 512px PNG). The 1024px PNGs and `.ico` files are in the download package (`.ico` is not an uploadable asset type).
- `mark-light.svg`, `mark-dark.svg`: the phone-in-orbit glyph in fixed colours (light: ink `#0b0b0b` + green `#5b7c26`; dark: `#f4f4f4` + `#a3bc69`). In the UI use the inline `pg-mark` instead, which follows the theme.
- `tray-online.svg`, `tray-offline.svg`, `tray-paused.svg`: 16 to 48px tray glyphs (ring + dot). Ink: fixed colours (online `#8bab4a`; offline ring `#8e8c99` with dot `#e2705a`; paused ring `#8e8c99` with dot `#e0a93a`), chosen to read on dark and light taskbars.
