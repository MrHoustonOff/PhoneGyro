Шаг 1. Скачивание и первичная настройка

Важно

Этот текст не стоит воспринимать за сухую документацию. Прочитайте его полностью, чтобы избежать проблем: на это уйдёт буквально 5 минут.

Скачайте последнюю версию со страницы релизов: Скачать PhoneGyro

Безопасность и антивирусы

Скорее всего, ваш антивирус или встроенный Windows Defender (SmartScreen) будет ругаться на скачанный .exe файл, а возможно, и вовсе молча заблокирует его.

Заметка

PhoneGyro — полностью открытый проект (Open Source). Если у вас есть хоть капля сомнений:

  1. Откройте исходный код в репозитории и прочитайте каждую строчку.
  2. Соберите бинарник самостоятельно с помощью Go и Wails.

Если вы доверяете — достаньте файл из карантина и нажмите в окне Windows: Подробнее → Выполнить в любом случае.

При первом запуске на ПК нажмите кнопку Initial Setup (Первичная настройка). Откроется QR-код для установки защищённого локального канала между телефоном и компьютером.

Настройка смартфона: Android

На Android ничего устанавливать не нужно:

  1. Сканируйте камерой QR-код первого шага и перейдите по локальной ссылке https://….
  2. Chrome покажет предупреждение «Подключение не защищено».
  3. Нажмите внизу: Дополнительно → Перейти на сайт … (небезопасно).
  4. Готово! Браузер запомнит исключение для вашего домашнего IP.

Настройка смартфона: iOS (iPhone)

Настройка под iOS показана пошагово прямо в приложении, со скриншотами.
