Two textures give the app its Hyrule feel without tinting the surfaces: a ring-and-wave tile on the window and a fine grain on cards. Both are neutral greys; they never carry hue.

- **`--tex-rings`** (from `assets/Textures/rings-light.svg` / `rings-dark.svg`): nested circles plus wavy lines, generated by the project's `zelda-rings.js` (seed 7, 30 circles, ring gap 16, stroke 6, wave gap 16, amplitude 5). Tile background equals `bg`; the stroke sits about 4% off it (`#f1f1f1` / `#e7e7e7` in light, `#0b0b0b` / `#191919` in dark). Apply on the window as `background-image: var(--tex-rings); background-size: 600px 600px`. It is opaque and seamless.
- **`--tex-grain`**: a 128px pre-rendered PNG noise tile embedded in `bundle.css` (black speckle in light, white in dark, about 5% alpha). It replaced the earlier SVG feTurbulence version (`assets/Textures/grain-*.svg`, kept for reference) because SVG filters are expensive and rendered unevenly inside scrolling layers. Apply on cards as `background: var(--surface) var(--tex-grain)`.
- Both variables are defined in `bundle.css` per theme, so changing `data-theme` swaps them.

**Rules**
- Rings only on `bg` (window, hero areas) and inside the viewport as geometry (`pg-rings-floor`). Cards, inputs and charts get grain or nothing.
- Do not raise stroke contrast above the values here: ring lines stay under 1.1:1 against `bg` so they read as texture, not content. To regenerate, change `background` / `stroke` in the generator, keep the seed.
- Motion is optional and slow: `pg-drift` moves the tile by exactly one tile over 120s with `transform`; it stops under `prefers-reduced-motion`. Off on the telemetry screen.
- Never animate `background-position`, blur the layer or inline the SVG into the DOM.
