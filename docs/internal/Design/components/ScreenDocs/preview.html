Step 1. Download and initial setup

Important

This guide is not dry documentation. Read it fully to avoid problems later: it takes literally 5 minutes.

Download the latest version from GitHub Releases: Download PhoneGyro

Security and antivirus warnings

Most likely your antivirus or built-in Windows Defender (SmartScreen) will complain about the downloaded .exe or silently block it.

Note

PhoneGyro is a 100% transparent open-source project. If you have any doubt:

  1. Read every line of code in the repository.
  2. Build the executable yourself with Go and Wails.

If you trust it, restore the file from quarantine and/or click in Windows: More info → Run anyway.

On first launch on the PC click Initial Setup. A QR code opens to set up a secure local channel between phone and computer.

Smartphone setup: Android

On Android nothing needs to be installed:

  1. Scan the Step 1 QR code with the camera and open the local https://… link.
  2. Chrome shows the standard warning “Your connection is not private”.
  3. Tap Advanced → Proceed to … (unsafe).
  4. Done. The browser remembers the exception for your home IP.
