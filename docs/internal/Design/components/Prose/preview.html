Step 1. Download and initial setup

Download the latest version of PhoneGyro from GitHub Releases. On first launch click Initial Setup and a QR code opens.

Important

Read this guide once: it takes literally 5 minutes and saves hours later.

Security and antivirus warnings

Windows may flag the .exe. The project is open source, so you can build it yourself with Go and Wails.

Note
  1. Read the source in the repository.
  2. Or restore the file and click More info → Run anyway.

Android

  1. Scan the QR code and open the https://… link.
  2. Tap Advanced → Proceed.
Tip
