# Cemu: баг дрейфа гироскопа — статус и материалы

Состояние на 2026-09-29 (вечер).

## Суть

В BotW прицел уплывает, пока контроллер лежит. Причина — в самом Cemu, не в PhoneGyro:
- `src/input/motion/Mahony.h updateGyroBias` — смещение = среднее всех образцов < 0.35 рад/с за весь сеанс, без
  забывания. Медленное прицеливание становится «смещением».
- `src/input/motion/MotionSample.h getVPADGyroChange` — фильтр шума 0.012 рад/с никогда не работал.

Воспроизводится и с посторонним DSU-сервером (MotionSource для Android), PadTest в это время показывает нули.
