00At a glance

PhoneGyro in a nutshell

PhoneGyro is a free, open-source Windows app. It takes gyroscope and accelerometer data from a phone or a DIY IMU device and serves it to emulators as a Cemuhook DSU server.

What it is
A Windows app that turns the gyroscope of a phone or your own IMU device into a motion controller for emulators.

01How it works

Three steps to a working gyro

01

Launch PhoneGyro

The app shows a QR code and an address. Data travels over your own Wi-Fi.

192.168.31.82:8443
02

Scan the QR code

With the phone camera. The controller page opens in Safari or Chrome; nothing to install.

iPhone? On iOS, install your own local certificate once; PhoneGyro generates it on your computer.
03

Connect the emulator

PhoneGyro runs as a Cemuhook DSU motion server. Enter 127.0.0.1:26760 in the emulator’s input settings.

04Questions

Questions and answers

How do I use my phone as a gyro in Cemu?

Start PhoneGyro, connect the phone with the QR code and add a DSU client in Cemu’s input settings: address 127.0.0.1, port 26760. Every setting is described in the Cemu guide and in the app’s Docs tab.

Does the phone gyro work in Ryujinx?

Yes, as long as the emulator has the Cemuhook DSU motion source on. PhoneGyro runs exactly that kind of server, so setup matches any DSU source.

Do I need an app on iPhone or Android?

No. The phone opens the controller page in Safari or Chrome. On iOS you install the local certificate PhoneGyro creates, once.

Can I do Zelda: TotK shrines without a Switch pad?

The game uses gyro for precise aiming. PhoneGyro passes the emulator your phone’s motion in place of a controller, so a separate Nintendo controller is not required.

How is PhoneGyro different from GyroBridge?

It is the same project. GyroBridge was renamed PhoneGyro, the UI moved to Wails (Go + Vite), and built-in calibration, 3D telemetry and iOS certificates were added.

Can I use a DIY controller instead of a phone?

Yes. The controller connects over USB and must send data in the format described in the device contract. Otherwise it behaves like a phone: PhoneGyro hands its motion to the emulator over DSU.

Where do I download PhoneGyro?

The latest Windows build is in Releases on GitHub. The “Download for Windows” button goes there: github.com/MrHoustonOff/PhoneGyro.
