# Данные и удаление

Всё, что PhoneGyro сохраняет, лежит в ***одной папке***: `%APPDATA%\PhoneGyro`. Путь и кнопка **Открыть папку** есть в [Настройках](settings.ru.md), пункт **«Папка данных»**. Сменить папку нельзя.

![Настройки: папка данных](imgs/settings.webp)

## Что там лежит

| Что | Где |
|---|---|
| Настройки | `settings.json` |
| Профили калибровки | `profiles.json`; профили USB-контроллера в подпапке `usb` |
| Сертификат для iPhone | папка `ca` |
| Журналы работы | папка `logs` (пригодятся, если нужно [сообщить о проблеме](issues.ru.md)) |
| Служебные данные окна | папки `WebView2_*` |

Устанавливать PhoneGyro не нужно, программа — один файл `PhoneGyro.exe`. Его можно переносить куда угодно, настройки от этого не пропадут.

## Сбросить настройки

Закройте PhoneGyro (в том числе в трее) и удалите папку данных. При следующем запуске программа начнёт с чистого листа.

> [!WARNING]
> Вместе с папкой удаляются профили калибровки и сертификат. На iPhone сертификат придётся установить заново ([Сертификаты и TLS](tls.ru.md)).

## Полностью удалить PhoneGyro

1. Закройте PhoneGyro, в том числе в трее.
2. Удалите `PhoneGyro.exe`.
3. Удалите папку `%APPDATA%\PhoneGyro`.
4. На iPhone или iPad: **Настройки → Основные → VPN и управление устройством**, удалите профиль **PhoneGyro Root CA (имя ПК)**. В старых версиях он назывался **PhoneGyro Controller Profile**.
5. Если в брандмауэре Windows остались разрешающие правила для PhoneGyro, их можно удалить в настройках брандмауэра.
