# Скриншоты интерфейса

Снимки экранов PhoneGyro (дока, ревью) — без Windows и без PhoneGyro.exe. Фронтенд открывается в headless Chrome с мок-бэкендом бенча (`tools/bench-daemon`). Сплэш проигрывается, устройство подключается, затем открывается нужный экран.

```sh
node tools/screenshot/shot.mjs --screen docs out/docs.png
node tools/screenshot/shot.mjs --screen connect --motion main.png -- --screen stats --lang en stats-en.png
```

Нужен Node.js 22+ и Chrome/Chromium (тот же поиск браузера, что у бенча). Сторонние пакеты не нужны.

| Опция | Что делает |
|---|---|
| `--screen` | экран: `connect` (по умолчанию), `stats`, `settings`, `docs`, `games` или `calibration` |
| `--lang ru\|en`, `--theme dark\|light`, `--zoom 1.25` | язык, тема, масштаб интерфейса |
| `--width 1280 --height 720 --dpr 1` | размер окна в css px и плотность пикселей |
| `--device "Nano MPU-6050"` | имя подключённого устройства |
| `--offline` | без устройства |
| `--motion` | живое движение и 2 DSU-клиента (Cemu, PadTest) |
| `--click "#sel"` | кликнуть по элементу перед снимком; можно повторять |
| `--eval "js"` | выполнить JS на странице перед снимком; можно повторять |
| `--wait 600` | сколько мс дать экрану успокоиться |
| `--clip "#sel"` | снять один элемент |
| `--full` | вся высота прокручиваемого экрана |

Несколько снимков за один запуск разделяются `--`: браузер запускается один раз, это быстрее. Опции переходят на следующий снимок, пока их не задать заново.

3D рисуется программно (SwiftShader): выглядит как надо, но медленно. Для 3D ставь `--wait 2500`. Ошибки страницы печатаются в конце.
